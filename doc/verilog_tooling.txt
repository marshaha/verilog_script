*verilog_tooling.txt*  Emacs verilog-mode AUTOs + automatic.vim in Python

==============================================================================
COMMANDS                                                      *verilog_tooling*

AALL        full AUTO set (EAP -> EAI -> AW -> AREG -> AD -> AR -> AF)
EAI         verilog-mode AUTOINST (regexp AUTO_TEMPLATE, .*, interfaces)
EAP         verilog-mode AUTOINSTPARAM (template, or default value)
AIT AIU AIU1  instantiate template / update instances (manual connections
              survive unless the AUTO_TEMPLATE declares that port)
AD ADT      regenerate /*autodef*/ declarations (wire/reg/integer/genvar)
AR          regenerate /*autoarg*/ header port lists
AW AREG     AUTOWIRE / AUTOREG
AF          format: ports, wire/reg, parameter/localparam, instances
AIF APF ADF   individual format passes
AM AME APM AFM  module/parameter/FSM snippets
AH ATpl     file header / new file from template
KI KAR KADT kill (collapse) AUTO regions
BPN BP BA   module header / always snippets

A count before EAI/AIT/AIU selects the Nth /*autoinst*/ instance.
Every command reports its change: [verilog_tooling] cmd: line N: a -> b line(s)

==============================================================================
OPTIONS

g:verilog_tooling_python      interpreter override (default: python3)
g:verilog_tooling_libdirs     extra -y module search dirs (list)
g:verilog_tooling_eai_flags   extra flags for :EAI (list, e.g. ['--sort'])

Requires Python >= 3.8. The plugin checks once and warns if too old.

==============================================================================
LOCAL VARIABLES

Honored: verilog-library-directories (single/multi-line),
verilog-library-flags ("-y dir" "-f file.vc"), verilog-inst-file,
verilog-typedef-regexp, verilog-auto-inst-param-value.
vc files: -y / +incdir+ / -I / -v / +libext+.
